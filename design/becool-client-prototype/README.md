# BeCool Client High-Fidelity Prototype

This prototype board is generated from the running mobile client at a `390 × 844` viewport.

Included screens:

- Home discovery
- Browse catalogue
- Product detail
- Shopping bag
- Sign in
- Create account
- Checkout (authenticated prototype state)
- My orders (authenticated prototype state)

Open `index.html` through the local preview server while the storefront development server is running on port `5175`.
